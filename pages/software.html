Waar draaien de diensten op?

Een dienst is de plek waar je iets gebruikt, zoals meetme.bit.nl. Daaronder draait software, zoals Jitsi Meet. Open source software kan iedereen draaien: stopt een aanbieder, dan ga je met dezelfde software naar een ander, of je host hem zelf. Per software zie je welke diensten erop draaien.
