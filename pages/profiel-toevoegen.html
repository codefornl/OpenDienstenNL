Profiel toevoegen

Een profiel laat zien welke diensten jouw organisatie gebruikt, en hoeveel daarvan open diensten zijn. Hier lees je hoe je er een maakt, en hoe je het zelf bijhoudt op je eigen website.

Waarom een profiel?

  • {% include atoms/hex.html %}
    Een wegwijzer voor je mensen

    Waarvoor moet ik waar zijn? Je stuurt je leden, medewerkers of vrijwilligers naar één link, bijvoorbeeld opendiensten.nl/?profiel=codefornl. Daar staat per onderwerp wat jullie gebruiken, en de knoppen Start videogesprek en Start samen schrijven kiezen uit jullie diensten.

  • {% include atoms/hex.html %}
    Je weg naar digitale autonomie

    Gebruik je iets wat (nog) geen open dienst is, zoals Slack of Google Docs, dan zet je dat er eerlijk bij. Het profiel laat zien hoeveel van je diensten al open zijn ({% include atoms/hex.html %} vol) en wat nog niet ({% include atoms/hex.html outline=true %} leeg), met waarom, en wat het open alternatief is.

  • {% include atoms/hex.html %}
    Inspiratie voor anderen

    Andere organisaties zien op Profielen welke diensten een vergelijkbare organisatie kiest.

Twee manieren

Makkelijk

Wij zetten het erop

Mail naar {{ site.email }} welke diensten je gebruikt, per onderwerp. Wij maken het profiel en zetten het op OpenDiensten. We zetten een profiel er alleen op als de organisatie daarom vraagt.

Aanbevolen

Je publiceert het zelf

Je zet één JSON-bestand op je eigen website. Wij halen het elke nacht op. Je houdt het zelf bij, en omdat het van jouw domein komt, is het meteen bevestigd. Ook dat is een stukje digitale autonomie.

Zelf publiceren, stap voor stap

  1. Kies je open diensten.

    Zoek op Diensten wat je gebruikt, of wilt gaan gebruiken. Noteer de id van elke dienst; die staan hieronder. Je hoeft de gegevens van een open dienst niet over te nemen: een verwijzing {"ref": "jitsi-meet-pleio"} is genoeg.

  2. Zet erbij wat (nog) geen open dienst is.

    Bekende diensten zoals Slack, WhatsApp, GitHub of LinkedIn staan al in Alle diensten, met de redenen waarom ze geen open dienst zijn. Verwijs ernaar, met de url waar jullie ze gebruiken: {"ref": "linkedin", "url": "https://www.linkedin.com/company/jullie-naam/"}. Dan gaat het kaartje in jullie profiel naar jullie pagina. Zo'n eigen url kan alleen bij een dienst die geen open dienst is: met een open dienst maak je steeds een nieuwe, unieke link.

    Staat de dienst er niet in, neem hem dan volledig op, met "open": false en de redenen: account (je moet een account maken), betaald, gesloten (gesloten software) of buiten-eu (aanbieder buiten de EU). De software en de aanbieder zijn id's uit onze lijsten van software en organisaties; staat de jouwe er niet in, vraag ons dan om hem toe te voegen.

  3. Maak het bestand.

    Neem het voorbeeld als begin. Kies een korte id voor je organisatie: kleine letters, cijfers en streepjes, bijvoorbeeld dorpshuis-zwammerdam. Die komt in je link: opendiensten.nl/?profiel=dorpshuis-zwammerdam.

  4. Controleer het.

    Het bestand volgt het schema profiel.schema.json, met dienst.schema.json voor een volledige dienst. Zet de regel "$schema" bovenaan, dan helpt een editor als VS Code je met aanvullen en controleren. Een online JSON Schema-validator kan ook.

  5. Zet het op je website.

    Op deze vaste plek, zodat het altijd te vinden is:

    https://<jouw-domein>/.well-known/opendiensten.json

    Het moet openbaar te lezen zijn, over https, en kleiner dan 1 MB. Meer is niet nodig: wij halen het op met een server, dus je hoeft niets in te stellen voor andere websites (CORS).

  6. Meld het aan.

    Mail de link naar {{ site.email }}. Wij zetten hem in het register. Daarna staat je profiel binnen een dag op Profielen.

  7. Houd het bij.

    Pas het bestand op je website aan; binnen een dag staat de nieuwe versie hier. Klopt het bestand niet, dan laten we de vorige versie staan, en hoor je van ons wat er mis is.

Een volledig voorbeeld

Een dorpshuis dat twee videodiensten gebruikt (de eerste heeft de voorkeur), Etherpad om samen te schrijven, en voorlopig nog WhatsApp om te chatten en een pagina op LinkedIn:

{
  "$schema": "https://opendiensten.nl/schemas/profiel.schema.json",
  "versie": 1,
  "id": "dorpshuis-zwammerdam",
  "naam": "Dorpshuis Zwammerdam",
  "beschrijving": "Het dorpshuis van Zwammerdam. Met deze diensten organiseren we activiteiten en vergaderingen.",
  "website": "https://www.dorpshuis-zwammerdam.nl",
  "logo": "https://www.dorpshuis-zwammerdam.nl/logo.png",
  "diensten": [
    { "ref": "jitsi-meet-pleio" },
    { "ref": "jitsi-meet-bit" },
    { "ref": "etherpad-disroot" },
    { "ref": "whatsapp" },
    { "ref": "linkedin", "url": "https://www.linkedin.com/company/dorpshuis-zwammerdam/" }
  ]
}

Let op: geen geheime links

Een profiel is openbaar. Zet er dus geen links in die toegang geven tot iets wat niet voor iedereen is: geen vaste vergaderkamer, geen gedeeld document, geen uitnodigingslink voor een besloten groep. Wie de link heeft, kan meedoen.

Verwijs liever naar de dienst zelf, of naar een openbare pagina die uitlegt hoe je erbij komt. Een eigen gesprek of document maak je met Start videogesprek en Start samen schrijven; die links blijven bij jou.

Open data: CC0

Met je profiel stel je de gegevens erin beschikbaar onder CC0: iedereen mag ze vrij gebruiken, kopiëren en verwerken, ook zonder bronvermelding. Dat geldt voor een profiel dat je aan ons doorgeeft, en voor een profiel dat je zelf publiceert en in het register laat opnemen.

Alle gegevens op OpenDiensten zijn CC0. Ze kloppen misschien niet allemaal; we geven er geen garantie op.

Vragen

Kan ik meerdere diensten per onderwerp kiezen?
Ja. De volgorde in je lijst is de volgorde van voorkeur. Start videogesprek kiest daartussen op basis van beoordelingen.
Moet alles een open dienst zijn?
Nee. Juist het eerlijke overzicht helpt: je ziet wat er nog te doen is. Wat geen open dienst is, staat met een dikke zwarte rand na de open diensten, en Start kiest het nooit.
Waarom op /.well-known/?
Dat is de gewone plek voor dit soort bestanden, zoals security.txt. Omdat het op jouw domein staat, weet iedereen dat het profiel van jou komt.
Kan ik verwijzen naar diensten uit het profiel van een andere organisatie?
Ja, met "bron": de link naar dat profiel, zoals die in het register staat.
Wat zien jullie van mijn mensen?
Niets. OpenDiensten heeft geen accounts en geen trackers, en wat iemand start of beoordeelt, blijft in de browser van die persoon. Zie Wat we bewaren.
