# Licentie van de gegevens

De gegevens in deze map (diensten, software, organisaties, profielen en het register) zijn open data onder
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/deed.nl): iedereen mag ze vrij gebruiken, kopiëren
en verwerken, ook zonder bronvermelding.

Ze kloppen misschien niet allemaal. We geven er geen garantie op. Een verbetering is welkom: info@apitecture.nl
of een pull request.

De code van OpenDiensten valt onder de EUPL-1.2 (zie LICENSE.md in de hoofdmap).
